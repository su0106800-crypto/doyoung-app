한 달 한 그루 — 웹사이트로 올리기

이 폴더 안의 파일(index.html, models 폴더, 아이콘, manifest.webmanifest)을 그대로 올리면 돼요.
폴더 구조를 바꾸지 마세요. index.html 옆에 models 폴더가 있어야 3D 모델이 나와요.

[방법 A] GitHub Pages (무료, 주소가 계속 유지돼요)
1. github.com 에서 새 저장소(New repository)를 만들어요. 이름 예: forest / 공개(Public)로.
2. 저장소 화면에서 "uploading an existing file"(또는 Add file > Upload files)을 눌러,
   이 폴더 안의 내용물(index.html, models 폴더, 아이콘들, manifest.webmanifest)을 전부 끌어다 놓고 Commit changes.
3. Settings > Pages > Build and deployment 에서 Source: Deploy from a branch,
   Branch: main, 폴더: / (root) 를 고르고 Save.
4. 1~2분 뒤 같은 화면 위쪽에 주소가 떠요: https://<아이디>.github.io/<저장소이름>/

[방법 B] Netlify Drop (가장 빠름)
1. https://app.netlify.com/drop 에 이 폴더(forest-site)를 통째로 끌어다 놓아요.
2. 바로 주소가 생겨요. 계정 없이도 올릴 수 있지만, 사이트를 계속 유지하려면 가입해서 사이트를 "claim" 하세요.
